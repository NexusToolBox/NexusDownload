# Contributing

Discuss substantial changes in [Issues][issues] before implementing them. Use Node.js 24, pnpm 12.18.0 and Windows for desktop work. Run `pnpm install`, `pnpm run check:boundaries`, `pnpm run lint`, `pnpm exec tsc --noEmit` and `pnpm test`. Build the portable release with `pnpm package:nexus`; Rust is required for bundled native helpers. Keep credentials and personal paths out of code, logs and screenshots. Preserve third-party notices.
