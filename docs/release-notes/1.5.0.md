## Improvements
- First public release for Windows 10 / 11 x64. Extract the ZIP and run.
- HTTP, magnet and BitTorrent downloads with resume, queues and schedules.
- File management and downloads for Baidu, Quark, UC, Aliyun, 115 and 123 cloud drives.
