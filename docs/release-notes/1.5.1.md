## Improvements
- Warn before adding duplicate URLs, cloud files and magnet links. Batch downloads skip duplicates by default; the warning can be disabled in settings.
- Use the new Alt+D global shortcut to open the add window from any app. The shortcut can be changed or cleared.

## Fixes
- Upgrades retain existing downloads and settings. Usage terms still require confirmation on the first launch of each version.
- The Windows portable package is currently unsigned.
