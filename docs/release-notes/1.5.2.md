- 软件更新、工具安装和普通下载默认跟随系统代理，运行中切换代理也会生效。

## Improvements
- App updates, tool installation and ordinary downloads now follow the system proxy by default, including proxy changes made while the app is running.
- Cloud drives and domestic media platforms connect directly by default, with an override in advanced network settings.
- A new update dialog combines release notes, download progress and restart controls. Slow downloads offer a browser download option.
- Advanced settings have consistent groups, and the license page shows each component's full license.
- Bilingual release notes display the section matching the interface language.

## Fixes
- Completed duplicate downloads prioritize opening the existing file to prevent accidental downloads with Enter.
- Corrected settings navigation, About row order, switch alignment and the RPC secret layout.
- Completed task details show file size and completion time without idle speed or redundant stages.
- Fixed wrapping in English and German task details and improved key interface labels across languages.
- The Windows portable package is currently unsigned.
