# 发布新版本

首次开源前，在 `src/shared/nexus-release-config.ts` 填写仓库与网站地址，运行 `node scripts/sync-nexus-release.mjs` 同步文档链接。使用 `scripts/export-public.ps1 -Destination 新目录` 导出公开源代码后，在新仓库启用 Actions。导出不包含开发历史或内部报告，也不会推送远程。

以后发布只需三步：

1. 运行 `node scripts/set-nexus-version.mjs 1.4.1` 更新版本号。
2. 编写 `docs/release-notes/1.4.1.md`，提交改动并推送代码。
3. 运行 `git tag v1.4.1` 和 `git push origin v1.4.1`。

标签版本须与 package.json 相同。Windows Actions 会完成检查、测试、打包，创建 Release 并上传 `NexusDownload-v1.4.1-win-x64.zip` 与同名 `.sha256` 附件，正文读取该版本的更新记录。当前发布未签名，应在每次更新记录中保留说明。手动运行发布流程只构建，不发布。

Windows 测试配置排除了保留的 Linux/macOS 打包、NAS/服务器集成、旧安装版发布、旧引导与内部文档工具测试，因为这些不属于本产品的 Windows 便携版运行范围。
