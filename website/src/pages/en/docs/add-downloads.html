Add on your computer

Select “Add download” or press Alt + D. Paste one link per line to add several at once, or drop a torrent file into the window.

Change or disable the shortcut under Settings → General → Global shortcut. Under Settings → Downloads, you can toggle “Autofill links from clipboard.”

Browser extensions

The portable build does not include a browser extension. If you already have a compatible one, turn on “Connect browser extensions” under Settings → Connections → Browser. Start pairing in the extension.

Send from phone

  1. Connect the phone and computer to the same local network. Turn on “Send from phone” under Settings → Connections.
  2. Scan the QR code with your phone. Enter the code shown on the phone in the desktop app and select “Pair device.”
  3. Paste the link on your phone and select “Send to computer.” Confirm the download on your computer.

Before you start

Review the files and save location. If you see “Already downloaded,” choose “Open file” or “Download again.”
