After a download

Open the file

For a completed task, choose “Open file” or open the folder containing it.

Organize by type

Turn on “Organize by type” under Settings → Downloads. Choose “Edit rules” to assign subfolders to matching files.

Extract a download package

In the package options, enable “Extract when package completes.” You can also enable “Recycle archives after extraction.” If a tool is missing, install it under Settings → External tools.
