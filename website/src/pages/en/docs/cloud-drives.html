Cloud drive accounts

Supports Baidu Netdisk, Quark, UC, 115, 123 Cloud and Aliyun Drive.

Sign in

Open Settings → Cloud accounts. Select “Sign in” next to your provider and follow its sign-in instructions.

Aliyun DriveRegister an application with Aliyun Drive Open Platform first. Follow the steps in “Set up Aliyun Drive” to enter the application ID and app secret.

Download files

  • Under Cloud drives, choose a provider and select files from “My files.”
  • For a share, select “Open shared link,” paste the link and access code, then select “Open shared folder.”

If a download address expires, the app tries to get a new one. If you are signed out, sign in again and retry.
