FAQ

Windows protected your PC

This build is unsigned. After verifying where you downloaded it, select “More info,” then “Run anyway.”

Is macOS or Linux supported?

The portable build is available for 64-bit Windows 10 and Windows 11 only.

A download is stuck at 0%

Check the task details. If the link has expired, copy a fresh one from the original page. If your cloud account shows “Signed out,” sign in again.

Downloads are not faster

Speed depends on your connection, the server and account limits. Check for speed limits under Settings → Downloads.

In-app updates are slow

Select “Download in browser” in the update dialog, or check that the proxy under Settings → Network is set to “Follow system.”

Report a problem

When you report an issue, include the app version and what you did. Do not include account details.
