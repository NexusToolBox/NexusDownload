Quick start

  1. Get the portable ZIP from the download page and extract it to a folder you can write to.
  2. Open NexusDownload.exe. Read the notice on first launch and select “Agree and continue.”
  3. Select “Add download” and paste a link. Review the files and save location, then start the download.
Windows protected your PCThis build is unsigned. After verifying where you downloaded it, select “More info,” then “Run anyway.”
