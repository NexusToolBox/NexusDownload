Settings & proxy

Performance and speed limits

Adjust “Simultaneous downloads” under Settings → Downloads. Set normal and low speed limits on the same page, and use the download schedule to switch between them.

Queues and schedules

Under Settings → Queues and schedules, create or edit a queue. Turn on “Enable schedule” and set the start and stop times. Under “After the queue is completed,” you can select an action such as shutting down.

Proxy

Under Settings → Network → Proxy, choose “Follow system,” “Off” or “Manual.” Cloud drives and domestic platforms connect directly by default. To route them through the proxy, turn on “Use proxy for cloud drives and domestic platforms” under Advanced → Proxy scope.

Language

Under Settings → General → Language, choose a language or follow the system.

Updates

Open Settings → About and select “Check.” If an update is available, select “Update,” then “Restart and update” when the download finishes.
