添加下载

支持哪些链接

类型例子
普通下载https://、http://、ftp:// 文件链接
BitTorrent.torrent 文件、magnet: 链接
网盘分享链接，或已登录账号中的文件
媒体受支持平台的视频或图集链接

在电脑上添加

点「添加下载」或按 Alt + D。可以一次粘贴多个链接，每行一个，也可以把种子文件拖进窗口。

在「设置 → 常规 → 全局快捷键」修改或关闭快捷键。在「设置 → 下载」可切换「自动填入剪贴板链接」。

浏览器扩展

便携版不附带浏览器扩展。已有兼容扩展时，在「设置 → 连接 → 浏览器」打开「连接浏览器扩展」，然后从扩展发起配对。

手机投递

  1. 让手机和电脑连接同一局域网。在「设置 → 连接」打开「手机投递」。
  2. 用手机扫二维码。在电脑上输入手机显示的配对码，点「配对设备」。
  3. 在手机上粘贴链接，点「发送到电脑」，再在电脑上确认下载。

开始前

核对文件和保存位置。若提示「已经下载过」，可选「打开文件」或「仍然下载」。
