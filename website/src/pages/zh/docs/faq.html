常见问题

Windows 已保护你的电脑

当前版本未签名。确认下载来源后，选择「更多信息」，再选「仍要运行」。

支持 macOS 或 Linux 吗？

目前仅提供 Windows 10 和 Windows 11 的 64 位便携版。

下载停在 0%

在任务详情中查看原因。地址过期时，从原网页重新复制；网盘账号显示「未登录」时，先重新登录。

下载速度没有变快

速度受网络、服务器和账号限制。检查「设置 → 下载」是否启用了限速。

软件内更新很慢

在更新窗口选择「在浏览器中下载」。也可以检查「设置 → 网络 → 代理」是否为「跟随系统」。

反馈问题

提交问题时附上软件版本和操作步骤，不要附上账号信息。
