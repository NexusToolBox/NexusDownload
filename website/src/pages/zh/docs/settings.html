下载设置与代理

性能与限速

在「设置 → 下载」调整「同时下载任务数」。在同一页设置常规限速和低速限速，可按「下载时间」切换。

队列与计划

在「设置 → 队列与计划」新建或编辑队列。打开「启用计划」后设置开始和停止时间。需要时可在「队列完成后」指定关机等操作。

代理

在「设置 → 网络 → 代理」选择「跟随系统」「不使用」或「手动」。网盘和国内平台默认直连；需要时可在「高级 → 代理范围」打开「网盘和国内平台也使用代理」。

语言

在「设置 → 常规 → 语言」切换语言，可选择跟随系统。

更新

打开「设置 → 关于」，点「检查」。有新版本时点「更新」，下载完成后选择「重启并更新」。
